# Contribution Rules

## 新增内容前

新增任何文件前，先确认它属于：

- 系统规则
- 治理规则
- 角色定义
- 原始输入
- 工作流
- 标准
- 模板
- 正式提示词
- AI 输出
- 案例
- 知识
- 评估
- 项目材料
- 归档

## 基本要求

- 一个文件只承担一种主要职责。
- 新增模板必须遵守模板标准。
- 新增案例必须保留完整生产链路。
- 新增标准必须说明适用范围。
- 新增工作流必须说明输入、步骤、输出和质量检查。

## 禁止事项

- 不把临时输出直接放入案例库。
- 不把具体业务内容写进通用模板。
- 不在 README 中堆积细节规则。
- 不创建没有职责说明的目录。
