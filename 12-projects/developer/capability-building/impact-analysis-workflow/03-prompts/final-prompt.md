# 最终提示词

```text
请参考 04-workflows/developer/impact-analysis-workflow.md，
基于下面的变更目标，先做影响范围分析。

变更目标：
【粘贴需求或变更说明】

请不要直接改代码。

请输出：

1. 变更边界。
2. 确定影响文件。
3. 可能影响文件。
4. 无需修改区域。
5. 调用链分析。
6. 接口影响。
7. 数据与状态影响。
8. 配置与环境影响。
9. 测试影响。
10. 文档影响。
11. 待确认问题。
12. 建议实现顺序。
13. 推荐下一步 developer-kit 工作流。

要求：
- 必须区分确定影响、可能影响、无需修改和待确认。
- 尽量给出具体文件路径。
- 必须包含测试影响和文档影响。
- 必须标出禁止修改或谨慎修改区域。
- 不能把局部需求扩大成全项目重构。
```
