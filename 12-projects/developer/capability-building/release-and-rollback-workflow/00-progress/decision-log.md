# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```
# 决策记录

## 2026-10-13：将“发布与回滚治理”独立为 developer-kit 工作流

### 背景

项目上线风险不只来自代码，也来自配置、环境、发布步骤、回滚缺失和上线后无人观察。

### 决策

将“发布与回滚治理”作为第三阶段第四个工作流。

### 原因

- 发布前需要检查代码、测试、文档、配置和阻塞问题。
- 发布失败必须有回滚或止损方案。
- 上线后需要观察指标、日志、业务路径和用户反馈。
- 发布异常应进入 AI 协作复盘。

### 影响

developer-kit 第三阶段能力链路变为：

```text
架构决策记录 -> 依赖与技术债治理 -> 环境配置治理 -> 发布回滚治理 -> AI 协作复盘
```
