## 沉淀价值

该能力让 developer-kit 的第二阶段闭环完成：

```text
代码实现执行 -> 测试与验收 -> 文档同步 -> 代码评审
```

它建立了一个关键规则：

```text
交付前必须用评审视角找问题，而不是只总结完成了什么。
```
