# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```
# 决策记录

## 2026-10-13：将“项目理解”独立为 developer-kit 基础工作流

### 背景

用户希望 AI 能够更好地协作管控项目开发，不只是执行代码修改。

### 决策

将“已有项目理解”独立为工作流，位于新项目启动治理之后、需求进入架构分析之前。

### 原因

- 已有项目和新项目的治理问题不同。
- 已有项目更需要先读懂结构、模块、边界和风险。
- 该能力能减少 Codex/Cursor 在陌生项目中误改、漏测和破坏边界的风险。

### 影响

developer-kit 第一阶段能力从“新项目启动”扩展为：

```text
新项目启动治理 -> 已有项目理解 -> 需求到架构影响分析
```
