## 沉淀价值

该能力让 developer-kit 不只适用于新项目，也能适用于已有项目接手。

它将“读项目”从随意行为变成稳定流程：

```text
读入口 -> 判技术栈 -> 看目录 -> 找模块 -> 定边界 -> 看协作 -> 找风险 -> 给下一步
```
