# 已有项目理解工作流建设项目

状态: completed
角色: developer
项目类型: capability-building
创建日期: 2026-10-13

## 目标

建设 developer-kit 的“已有项目理解工作流”，让 AI 在接手已有代码项目时，先输出项目理解报告，再进入后续开发。

## 角色

开发治理架构师 / AI 协作开发工程师。

## 输入材料

输入资料来自用户对 developer-kit 的整体目标：希望 Codex、Cursor 能在已有项目中理解项目结构、模块边界、协作方式和风险，而不是直接改代码。

## 使用的工作流

```text

```

## 使用的模板
