# 最终提示词

```text
请参考 04-workflows/developer/project-understanding-workflow.md，
帮我理解当前已有项目。

请先阅读项目根目录中的 README、AGENTS、docs、.cursor/rules、技术栈入口文件、主要源码目录和测试目录。

请不要直接修改代码。

请输出一份项目理解报告，包含：

1. 项目一句话定位。
2. 已确认事实。
3. 基于文件结构的推断。
4. 仍需我确认的问题。
5. 技术栈与运行方式。
6. 目录职责地图。
7. 核心模块地图。
8. 模块边界说明。
9. 模块协作链路。
10. 风险与缺口。
11. 是否适合进入开发。
12. 推荐下一步使用哪个 developer-kit 工作流。

要求：
- 每个关键判断尽量给出文件证据。
- 区分事实、推断和待确认问题。
- 如果项目缺少基础治理文件，请建议使用 project-bootstrap-workflow.md 补齐。
- 如果需要继续开发，请说明进入开发前还需要确认什么。
```
