# 最终提示词

```text
请参考 04-workflows/developer/testing-verification-workflow.md，
基于本次代码变更，帮我做测试与验收。

请先根据修改文件、影响范围和风险等级制定验证计划。

然后运行当前项目中可执行的测试、构建、类型检查或 lint 命令。

请输出测试与验收报告，包括：

1. 验证目标。
2. 验证计划。
3. 已运行验证。
4. 手动验收步骤。
5. 回归检查范围。
6. 未验证内容。
7. 失败与处理。
8. 是否建议交付。
9. 后续建议。

要求：
- 测试失败不能写成通过。
- 无法验证必须说明原因。
- 手动验收步骤必须可复现。
- 交付判断必须基于验证结果。
```
