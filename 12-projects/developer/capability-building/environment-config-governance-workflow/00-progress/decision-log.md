# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```
# 决策记录

## 2026-10-13：将“环境与配置治理”独立为 developer-kit 工作流

### 背景

环境变量、启动配置、构建配置和部署配置容易在长期维护中失真，导致本地可用但测试或生产不可用。

### 决策

将“环境与配置治理”作为第三阶段第三个工作流。

### 原因

- 配置变更可能影响启动、构建、测试和发布。
- 敏感信息需要明确禁止入库。
- 环境差异需要被记录和验证。
- 配置变更是发布回滚治理的重要前置输入。

### 影响

developer-kit 第三阶段能力链路变为：

```text
架构决策记录 -> 依赖与技术债治理 -> 环境配置治理 -> 发布回滚治理 -> AI 协作复盘
```
