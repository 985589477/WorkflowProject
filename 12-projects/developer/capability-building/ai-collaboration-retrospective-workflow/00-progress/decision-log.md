# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```
# 决策记录

## 2026-10-13：将“AI 协作复盘”独立为 developer-kit 工作流

### 背景

developer-kit 需要具备自我改进能力，将 AI 协作中的问题反哺为规则、模板、评分表或后续能力建设。

### 决策

将“AI 协作复盘”作为第三阶段最后一个工作流。

### 原因

- AI 协作问题如果不沉淀会重复发生。
- 复盘可以区分偶发问题和规则缺口。
- 改进动作需要具体到文件、规则或能力。

### 影响

developer-kit 三阶段能力链路完成：

```text
开发前治理 -> 开发过程治理 -> 长期维护治理
```
