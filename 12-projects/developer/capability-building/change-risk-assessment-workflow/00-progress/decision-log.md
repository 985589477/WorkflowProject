# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```
# 决策记录

## 2026-10-13：将“变更风险评估”独立为 developer-kit 工作流

### 背景

用户希望 AI 能够更好地管控项目开发，避免高风险变更被直接执行。

### 决策

将“变更风险评估”作为模块边界分析之后、影响分析和实现之前的独立工作流。

### 原因

- 不同风险等级需要不同执行策略。
- 高风险和危险变更必须有人工确认。
- 变更前应明确验证和回滚要求。

### 影响

developer-kit 第一阶段能力链路变为：

```text
新项目启动治理 -> 已有项目理解 -> 需求到架构影响分析 -> 模块边界分析 -> 变更风险评估 -> 影响范围分析
```
