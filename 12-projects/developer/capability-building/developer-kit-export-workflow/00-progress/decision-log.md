# 决策记录

## 2026-10-13：developer-kit 采用独立导出包结构

### 决策

将开发治理能力导出到：

```text
14-exports/developer-kit/
```

不直接复制整个 WorkflowProject。

### 原因

- 外部项目只需要开发治理能力，不需要 WorkflowProject 的完整项目管理结构。
- 独立导出包更适合复制、验证和后续安装为 skill。
- 与 `product-manager-kit` 保持一致，后续角色能力包可统一管理。

### 影响

- `04-workflows/developer/` 继续作为内部维护源。
- `14-exports/developer-kit/` 作为外部使用入口。
- 后续更新开发能力后，需要重新导出并更新导出时间。

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```
