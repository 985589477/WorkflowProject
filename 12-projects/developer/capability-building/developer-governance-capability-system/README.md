状态: completed

## 目标

建设 developer-kit 的开发治理能力体系。

本项目重点不是让 AI “会写代码”，而是让 Codex、Cursor 等 AI 开发工具在项目中能稳定协作、理解结构、控制风险、维护边界，并避免项目长期失控。

## 角色

- AI 协作开发治理架构师。
- 软件架构治理专家。
- 开发流程与质量评审专家。

## 输入材料

- 用户关于 developer-kit、Codex、Cursor、项目结构、模块边界、任务治理的讨论。
- 当前 WorkflowProject 已沉淀的产品经理能力包经验。
- Codex / Cursor 在真实项目协作中的风险点。
