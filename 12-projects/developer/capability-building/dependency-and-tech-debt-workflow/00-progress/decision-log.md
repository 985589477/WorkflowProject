# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```
# 决策记录

## 2026-10-13：将“依赖与技术债治理”独立为 developer-kit 工作流

### 背景

长期项目维护中，AI 容易为了短期方便引入依赖或留下临时方案，最终增加维护成本。

### 决策

将“依赖与技术债治理”作为第三阶段第二个工作流。

### 原因

- 新增依赖需要必要性和风险评估。
- 临时方案需要记录还债条件。
- 技术债需要影响范围、优先级和偿还计划。
- 高影响依赖决策需要判断是否进入 ADR。

### 影响

developer-kit 第三阶段能力链路变为：

```text
架构决策记录 -> 依赖与技术债治理 -> 环境配置治理 -> 发布回滚治理 -> AI 协作复盘
```
