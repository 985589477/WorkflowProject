# 需求变更评估工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-13

## 目标

建设产品经理能力体系中的需求变更评估工作流。

本项目负责在路线图、版本规划、PRD 或开发排期已经形成后，对新增需求、范围变化、优先级调整或需求取消进行影响评估。

它解决的是“变更能不能接、什么时候接、会影响什么、需要谁确认”的问题，不替代需求分析、PRD 和版本规划。

## 项目职责

这个项目负责生成并验证产品经理需求变更评估工作流。

它不直接批准具体变更，而是定义后续产品经理如何评估变更影响并输出建议。

## 角色

- 产品经理能力体系架构师。
- 需求变更评估工作流架构师。
- 输出质量评审专家。

## 输入材料

输入材料可以来自：

- 变更请求。
- 当前 PRD。
- 需求池。
- 产品路线图。
- 版本规划。
- 优先级判断。
- 开发排期、设计方案、测试计划或上线计划。
