# 原始需求

## 用户原始指令

请创建并推进产品经理 PRD 工作流建设项目，目标是基于已有需求分析结果，生成可复用的 PRD 生成工作流。

请使用这个真实案例作为测试输入：

```text
12-projects/product-manager/real-cases/ai-template-tool-requirement-analysis/
```

输出到：

```text
12-projects/product-manager/capability-building/prd-workflow/
```

## 参考输入

本项目使用以下真实案例作为测试输入：

```text
12-projects/product-manager/real-cases/ai-template-tool-requirement-analysis/02-analysis/requirement-analysis.md
12-projects/product-manager/real-cases/ai-template-tool-requirement-analysis/02-analysis/review-gap-resolution.md
12-projects/product-manager/real-cases/ai-template-tool-requirement-analysis/05-review/output-review.md
```

## 关键背景

需求分析项目已经明确：AI 提示词模板工具第一版不应只是提示词收藏夹，而应定位为 WorkflowProject 的 AI 协作资产导航层。

该需求分析可以进入 PRD 初稿，但 PRD 必须保留边界约束，不做权限、账号、商业模板市场和自动 AI 执行。

## 期望输出

- 一个可复用的 PRD 生成工作流。
- 工作流能明确输入、步骤、产物、质量标准和评审方式。
- 工作流能支持后续从需求分析结果生成 PRD。
- 工作流能沉淀到全局产品经理工作流目录。
