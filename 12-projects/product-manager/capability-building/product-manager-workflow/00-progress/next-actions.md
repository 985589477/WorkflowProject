# 下一步判断

## 使用说明

这里用于帮助用户判断项目下一步该往哪里走。

## 当前项目状态

已完成。

本项目已经验证：

- 用户一句模糊描述可以生成标准 input。
- 标准 input 可以继续进入输入分析。
- 新版产品经理 workflow 已生成。
- 新版 workflow 已提升到全局目录。

## 可选方向

### 方向 A：继续推进当前项目

- 价值：可以整理为 `09-examples/product-manager/` 下的案例。
- 风险：会增加一次案例整理工作。
- 建议：可以稍后做，当前优先验证真实 PRD。

### 方向 B：先补输入或上下文

- 价值：如果用户提供具体产品想法，可以继续跑 PRD 项目。
- 风险：如果继续只围绕 workflow，会停留在框架层。
- 建议：下一步不要继续抽象设计，应该跑真实产品输出。

### 方向 C：暂停并沉淀

- 价值：当前 v2 已经沉淀到全局工作流。
- 风险：没有真实 PRD 验证前，仍无法证明它足够好用。
- 建议：沉淀已完成，但不要在这里停太久。

## 推荐下一步

启动一个真实 PRD 项目，使用新版产品经理工作流验证：

```bash
python3 tools/create_project.py product-manager sample-prd --type real-cases
```

然后只给一句产品想法，让 `idea-to-input-generator` 先生成 input。
