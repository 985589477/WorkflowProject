# 功能规划工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的功能规划工作流。

本项目负责把产品目标、PRD、功能清单和业务约束整理成可执行的功能规划，明确哪些功能先做、哪些后做、哪些暂不做。

## 项目职责

这个项目负责生成并验证产品经理功能规划工作流。

它不直接维护某个具体产品的版本计划，而是定义后续产品经理如何把需求和 PRD 拆成结构化功能规划。

## 何时使用

当你要建设、优化或评审功能规划能力时，使用这个项目。

当你要执行一次具体功能规划任务时，使用本项目沉淀出的全局工作流：

```text
04-workflows/product-manager/feature-planning-workflow.md
```
