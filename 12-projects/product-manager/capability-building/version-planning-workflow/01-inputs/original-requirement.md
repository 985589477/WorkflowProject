# 原始需求

## 用户意图

按照产品经理能力建设顺序，继续建设判断和决策能力中的“版本规划工作流”。

## 能力定位

版本规划用于把产品目标、功能范围和优先级结果拆成阶段化路线。

它回答：

```text
v1 做什么？
v1.1 补什么？
v2 扩展什么？
哪些内容暂不进入路线？
每个版本为什么这样安排？
```

## 输入来源

版本规划可接受：

- 产品目标。
- 功能规划。
- 优先级判断。
- PRD。
- 用户反馈整理结果。
- 竞品分析结果。
- 资源约束。
- 时间约束。
- 风险和依赖。

## 期望输出

- 可复用的版本规划工作流。
- 可复用的版本规划模板。
- 可复用的版本规划评分表。
- 项目评审和沉淀记录。
