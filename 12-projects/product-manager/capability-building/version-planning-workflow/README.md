# 版本规划工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的版本规划工作流。

本项目负责把产品目标、功能规划、优先级判断、资源约束和风险整理成阶段化版本路线，明确 v1、v1.1、v2 分别做什么。

## 项目职责

这个项目负责生成并验证产品经理版本规划工作流。

它不直接决定某个具体项目的发布排期，而是定义后续产品经理如何规划版本阶段。

## 何时使用

当你要建设、优化或评审版本规划能力时，使用这个项目。

当你要执行一次具体版本规划任务时，使用本项目沉淀出的全局工作流：

```text

```
