# 输入分析

## 任务类型

这是产品经理能力建设项目，不是真实产品路线图规划项目。

本项目要建设的是一套可复用方法，让后续真实项目可以基于策略、需求池、优先级和版本规划生成产品路线图。

## 能力定位

产品路线图位于产品经理长期规划能力层。

它主要回答：

- 产品未来一段时间的方向是什么。
- 每个阶段的主题和目标是什么。
- 哪些需求、能力或版本进入路线图。
- 哪些内容暂不进入路线图。
- 阶段之间有什么依赖和演进逻辑。
- 路线图有哪些风险、假设和调整机制。

## 与已有能力的关系

| 能力 | 关系 |
| --- | --- |
| 产品策略判断 | 提供路线图主线和方向依据 |
| 需求池管理 | 提供候选需求、状态和来源 |
| 优先级判断 | 提供先后顺序和取舍依据 |
| 版本规划 | 提供短中期版本阶段 |
| PRD 生成 | 路线图确认后，具体事项可进入 PRD |

## 输出边界

产品路线图不直接写完整 PRD，不替代版本排期，也不承诺精确开发时间。

它应该输出：

- 路线图目标。
- 时间范围。
- 阶段主题。
- 关键能力或需求。
- 不进入路线图内容。
- 依赖、风险和假设。
- 后续动作。

## 质量重点

- 路线图必须有目标和阶段逻辑。
- 不能只是功能列表。
- 不能把所有需求都塞进路线图。
- 需要保留不确定性和调整机制。
- 需要能衔接 PRD、版本规划和开发排期。
