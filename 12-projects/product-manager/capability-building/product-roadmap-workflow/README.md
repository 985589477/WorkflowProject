# 产品路线图工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的产品路线图工作流。

本项目负责把产品策略判断、需求池、优先级判断、版本规划、业务目标和资源约束整理成中长期产品路线图。

它解决的是“未来一段时间产品往哪里走、每个阶段解决什么问题、哪些方向先后推进”的问题，不替代 PRD、版本规划和开发排期。

## 项目职责

这个项目负责生成并验证产品经理产品路线图工作流。

它不直接完成某个具体功能规划，而是定义后续产品经理如何规划季度、半年或年度产品方向。

## 角色

- 产品经理能力体系架构师。
- 产品路线图工作流架构师。
- 输出质量评审专家。

## 输入材料

输入材料可以来自：

- 产品策略判断结果。
- 需求池。
- 版本规划。
- 优先级判断。
- 竞品分析。
- 用户反馈整理。
- 业务目标、资源约束和关键时间节点。
