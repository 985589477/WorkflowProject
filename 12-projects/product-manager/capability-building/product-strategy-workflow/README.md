# 产品策略判断工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的产品策略判断工作流。

本项目负责把产品目标、用户问题、市场机会、竞品变化、业务约束和资源限制整理成可解释的策略判断，帮助产品经理判断一个方向是否值得做、为什么现在做、优先服务谁、成功标准是什么。

它解决的是“方向是否成立”的问题，不替代需求分析、PRD、优先级判断和版本规划。

## 项目职责

这个项目负责生成并验证产品经理产品策略判断工作流。

它不直接执行某个具体产品策略决策，而是定义后续产品经理如何判断产品方向、机会和阶段性策略。

## 角色

- 产品经理能力体系架构师。
- 产品策略工作流架构师。
- 输出质量评审专家。

## 输入材料

输入材料可以来自：

- 产品目标。
- 用户反馈整理结果。
- 需求分析结果。
- 竞品分析结果。
- 业务目标和资源约束。
- 当前版本规划或历史复盘。
