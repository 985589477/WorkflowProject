# 用户反馈整理工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的用户反馈整理工作流。

本项目负责把零散用户反馈、吐槽、客服记录、访谈摘录或社群讨论整理成问题分类、痛点、需求机会和优先级线索。

## 项目职责

这个项目负责生成并验证产品经理用户反馈整理工作流。

它不直接处理某个长期反馈池，而是定义后续产品经理如何从外部反馈中提炼产品机会。

## 何时使用

当你要建设、优化或评审用户反馈整理能力时，使用这个项目。

当你要执行一次具体用户反馈分析任务时，使用本项目沉淀出的全局工作流：

```text
04-workflows/product-manager/user-feedback-workflow.md
```

## 输入材料

输入材料可以来自：

- 用户原始反馈。
- 客服记录。
- 用户访谈摘录。
- 社群聊天记录。
- 应用商店评论。
- 内部使用反馈。

本项目使用当前 WorkflowProject 历史对话中的典型反馈作为抽象样例，例如：

```text
项目文件很多，我不知道当前有什么。
项目过几天就忘记是干什么的。
只看目录很难构建全局观。
我不知道如何启动某个项目。
```
