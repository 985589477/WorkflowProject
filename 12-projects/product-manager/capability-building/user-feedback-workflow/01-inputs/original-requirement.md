# 原始需求

## 用户意图

按照产品经理能力建设顺序，开始建设外部输入处理能力中的“用户反馈整理工作流”。

## 能力定位

用户反馈整理用于把零散反馈整理成结构化产品线索。

它位于需求分析之前：

```text
用户反馈
↓
用户反馈整理
↓
需求机会 / 问题归类
↓
需求分析
↓
PRD
```

## 示例反馈

```text
项目文件很多，我不知道当前有什么。
项目过几天就忘记是干什么的。
只看目录很难构建全局观。
我不知道如何启动某个项目。
```

## 期望输出

- 可复用的用户反馈整理工作流。
- 可复用的用户反馈整理模板。
- 可复用的用户反馈评分表。
- 项目评审和沉淀记录。
