# 原始需求

## 用户想法

继续完成产品经理能力建设，下一项建设需求池管理工作流。

## 背景

当前产品经理能力体系已经具备需求分析、PRD、验收标准、功能规划、用户故事、用户反馈、竞品分析、优先级判断、版本规划和产品策略判断能力。

这些能力会不断产生新的需求、机会点、待确认问题和后续动作。如果没有需求池管理能力，需求会分散在不同项目文档中，后续很难追踪：

- 需求从哪里来。
- 当前是什么状态。
- 是否已经分析过。
- 是否进入 PRD。
- 是否进入版本。
- 为什么暂缓或放弃。
- 后续谁来继续推进。

## 目标

生成一个可复用的需求池管理工作流，并沉淀为全局能力文件。
