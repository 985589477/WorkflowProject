# 需求池管理工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的需求池管理工作流。

本项目负责把来自用户反馈、需求分析、竞品分析、产品策略判断、业务方输入和团队讨论的需求，整理成可长期维护的需求池。

它解决的是“需求进来以后如何保存、分类、判断、流转和更新”的问题，不替代需求分析、优先级判断、PRD 和版本规划。

## 项目职责

这个项目负责生成并验证产品经理需求池管理工作流。

它不直接完成某一个具体需求，而是定义后续产品经理如何管理多个需求的生命周期。

## 角色

- 产品经理能力体系架构师。
- 需求池管理工作流架构师。
- 输出质量评审专家。

## 输入材料

输入材料可以来自：

- 用户反馈整理结果。
- 需求分析结果。
- 产品策略判断结果。
- 竞品分析结果。
- 业务方需求。
- 会议纪要。
- 已有功能清单、版本规划或历史需求池。
