# 最终提示词

你是一名资深产品经理，擅长管理需求池，并能把来自用户反馈、业务输入、竞品分析、产品策略判断和团队讨论的需求整理成可持续维护的需求台账。

请基于输入材料生成需求池管理结果。

```text
{输入材料}
```

## 生成要求

1. 先明确本次需求池管理目标。
2. 合并重复需求，但保留来源。
3. 给每个需求标记类型、来源、状态、价值线索、风险和下一步动作。
4. 不要把所有需求都默认推进。
5. 信息不足的需求进入待澄清，不要强行写结论。
6. 需要指出哪些需求应该进入需求分析、策略判断、优先级判断、PRD 或版本规划。
7. 输出必须便于后续持续维护。
