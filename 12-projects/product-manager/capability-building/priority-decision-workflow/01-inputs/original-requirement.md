# 原始需求

## 用户意图

按照产品经理能力建设顺序，继续建设判断和决策能力中的“优先级判断工作流”。

## 能力定位

优先级判断用于在多个需求、功能或机会之间做取舍。

它回答：

```text
哪些先做？
哪些后做？
哪些暂不做？
为什么？
还有哪些信息不足，不能贸然判断？
```

## 输入来源

优先级判断可接受：

- 功能清单。
- 用户反馈整理结果。
- 竞品分析结果。
- PRD。
- 产品目标。
- 业务目标。
- 资源约束。
- 风险和待确认问题。

## 期望输出

- 可复用的优先级判断工作流。
- 可复用的优先级判断模板。
- 可复用的优先级判断评分表。
- 项目评审和沉淀记录。
