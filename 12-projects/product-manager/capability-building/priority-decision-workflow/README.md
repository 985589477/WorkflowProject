# 优先级判断工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的优先级判断工作流。

本项目负责把需求、功能、用户反馈、竞品机会和业务约束转化为可解释的优先级建议，帮助判断先做什么、后做什么、暂不做什么。

## 项目职责

这个项目负责生成并验证产品经理优先级判断工作流。

它不直接决定某个具体项目的排期，而是定义后续产品经理如何做优先级判断。

## 何时使用

当你要建设、优化或评审优先级判断能力时，使用这个项目。

当你要执行一次具体优先级判断任务时，使用本项目沉淀出的全局工作流：

```text
04-workflows/product-manager/priority-decision-workflow.md
```
