# 原始需求

## 用户意图

按照产品经理能力建设顺序，继续建设外部输入处理能力中的“竞品分析工作流”。

## 能力定位

竞品分析用于把竞品资料整理为产品启发。

它不等于抄竞品，而是帮助产品经理识别：

- 竞品怎么解决类似问题。
- 竞品功能结构是什么。
- 有哪些可借鉴点。
- 有哪些差异机会。
- 有哪些不能照搬的风险。

## 输入来源

竞品分析可接受：

- 竞品官网或产品页面。
- 截图。
- 功能说明。
- 体验笔记。
- 帮助文档。
- 价格页。
- 用户评价。

## 期望输出

- 可复用的竞品分析工作流。
- 可复用的竞品分析模板。
- 可复用的竞品分析评分表。
- 项目评审和沉淀记录。
