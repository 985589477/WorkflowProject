# 竞品分析工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的竞品分析工作流。

本项目负责把竞品资料、截图、页面结构、功能描述或体验记录整理成竞品功能拆解、差异点、可借鉴点、风险和产品机会。

## 项目职责

这个项目负责生成并验证产品经理竞品分析工作流。

它不直接长期维护某个竞品库，而是定义后续产品经理如何从竞品资料中提炼产品启发。

## 何时使用

当你要建设、优化或评审竞品分析能力时，使用这个项目。

当你要执行一次具体竞品分析任务时，使用本项目沉淀出的全局工作流：

```text
04-workflows/product-manager/competitor-analysis-workflow.md
```
