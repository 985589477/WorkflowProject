# 输入分析

## 输入是否充足

输入充足。

当前能力建设目标明确：需要抽象竞品分析流程，而不是分析某个具体竞品。

## 竞品分析要解决的问题

竞品资料通常包含页面、功能、定价、文案、交互和用户评价。如果没有结构化分析，容易出现：

- 只罗列竞品功能。
- 把竞品方案直接当成自己的方案。
- 忽略竞品背后的用户场景。
- 忽略差异机会。
- 忽略不能照搬的风险。

## 设计原则

1. 先明确分析目标。
2. 区分竞品事实、AI 推断和产品启发。
3. 不把竞品方案直接等同于我方需求。
4. 同时提炼可借鉴点和风险。
5. 输出必须能进入需求分析、产品策略或功能规划。

## 输出结构建议

竞品分析应至少包含：

- 分析目标。
- 竞品范围。
- 竞品概览。
- 功能拆解。
- 用户场景。
- 差异点。
- 可借鉴点。
- 风险和误区。
- 产品机会。
- 后续建议。
