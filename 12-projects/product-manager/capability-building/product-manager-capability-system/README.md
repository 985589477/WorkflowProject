状态: draft
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

规划产品经理后续能力细分体系，形成可以指导后续 workflow、template、example 和 evaluation 建设的总地图。

## 项目职责

这个项目负责规划“产品经理能力体系地图”。

它承担的职责不是跑某个具体产品任务，而是帮助判断产品经理角色后续应该建设哪些能力模块、哪些能力优先、每个能力未来应该沉淀哪些 workflow、template、example 和 evaluation。

## 何时使用

当你不是要完成一个具体产品输出，而是要决定产品经理体系接下来怎么建设时，使用这个项目。

典型场景：

- 我想知道产品经理后续应该补哪些能力。
- 我想决定先做需求分析、PRD、验收标准还是竞品分析。
- 我想规划产品经理 workflow 和 template 的建设路线。
- 我想避免只堆文档，而是形成产品经理能力体系。

## 和总入口工作流的关系

`product-manager-capability-system` 负责告诉你产品经理有哪些能力、建设顺序是什么。

`product-manager-workflow` 负责在具体任务执行时调用这些能力。
