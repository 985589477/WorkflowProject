# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```

## 决策：建设产品经理能力体系，而不是单点文档

### 背景

用户希望产品经理后续建设不是只输出一个文档，而是形成可持续扩展的体系。

### 决策

本项目输出产品经理能力体系地图，覆盖能力分层、核心模块、优先级、后续项目拆分和沉淀路径。

### 原因

能力体系能指导后续不断生成和验证细分 workflow、template、example 和 evaluation。

### 影响

后续产品经理建设应优先参考：

```text
10-knowledge-base/patterns/product-manager-capability-system.md
```

### 日期

2026-10-12

## 决策：优先沉淀到知识库

### 背景

能力体系不是某个单独 workflow，也不是某个正式提示词。

### 决策

将能力体系沉淀到：

```text
10-knowledge-base/patterns/product-manager-capability-system.md
```

同时更新产品经理角色定义和工作流 README。

### 原因

知识库更适合作为跨项目、跨资产的体系地图。

### 影响

后续项目创建、角色理解和产品经理工作流扩展都可以引用该文件。

### 日期

2026-10-12
