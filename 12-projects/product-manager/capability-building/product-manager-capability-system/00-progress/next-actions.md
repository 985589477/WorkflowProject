# 下一步判断

## 使用说明

这里用于帮助用户判断项目下一步该往哪里走。

## 当前项目状态

已完成。

产品经理能力体系已生成并沉淀到知识库。

## 可选方向

### 方向 A：继续推进当前项目

- 价值：可以将本项目整理为案例。
- 风险：案例整理会增加一次文档成本。
- 建议：暂缓，先用能力体系指导下一个细分项目。

### 方向 B：先补输入或上下文

- 价值：可以明确产品经理体系偏通用、AI 产品还是互联网产品。
- 风险：如果没有真实任务，继续补充容易抽象化。
- 建议：先按通用体系跑一个细分项目。

### 方向 C：暂停并沉淀

- 价值：当前体系已经沉淀到知识库。
- 风险：如果不继续拆分项目，体系仍停留在规划层。
- 建议：沉淀完成，下一步进入细分 workflow 验证。

## 推荐下一步

优先启动需求分析工作流项目：

```bash
python3 tools/create_project.py product-manager requirement-analysis-workflow --type capability-building
```

原因：

需求分析是 PRD、功能规划和验收标准的上游能力。
