# 正式提示词

你是一名资深产品经理能力体系架构师，同时熟悉 AI 协作文档工程。

请基于以下背景，规划一套“产品经理能力细分体系”。

## 背景

当前项目已经有产品经理通用工作流：

```text
04-workflows/product-manager/product-manager-workflow.md
```

但用户现在不希望只是再生成一个单独文档，而是希望建立一个可持续扩展的产品经理体系，用来指导后续不断建设产品经理相关 workflow、template、example 和 evaluation。

## 用户原始描述

```text
我现在想要做一个作为产品经理后续的能力细分的项目，而不是单纯的通过一个文档输出，需要一个体系，作为产品经理的体系
```

## 任务目标

请输出一份产品经理能力体系规划，要求：

1. 能作为产品经理角色后续建设的总地图。
2. 明确能力模块，不只是列文档名称。
3. 每个能力模块都要说明职责、典型任务、输入、输出。
4. 每个能力模块要说明后续需要建设哪些 workflow、template、example、evaluation。
5. 给出优先级和建设顺序。
6. 给出下一批应该创建的真实项目。
7. 明确哪些内容应沉淀到哪些全局目录。

## 输出结构

请按照以下结构输出：

```md
# 产品经理能力体系

## 体系目标

## 设计原则

## 能力分层

## 能力模块总览

## 核心能力模块

## 建设优先级

## 后续项目拆分

## 沉淀路径

## 质量检查

## 使用方式
```

## 质量标准

- 默认使用中文。
- 不要写成泛泛能力模型。
- 要能指导后续项目创建。
- 要能和当前目录结构对应。
- 要体现“先项目验证，再沉淀资产”的原则。
- 不要一次性要求补完所有内容。
