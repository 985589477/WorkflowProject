# 原始需求

## 用户想法

把产品经理主链路最后一个核心工作流做完：版本复盘工作流。

## 背景

当前产品经理能力体系已经具备从想法、需求分析、PRD、验收标准、功能规划、用户故事、反馈、竞品、优先级、版本规划、策略判断、需求池、路线图到需求变更评估的能力。

还缺少版本结束后的复盘能力，用来回答：

- 版本目标是否达成。
- 需求是否按计划交付。
- 中途变更造成了什么影响。
- 哪些问题来自需求、设计、开发、测试或协作。
- 用户和数据反馈说明什么。
- 下一轮产品规划应该如何调整。
- 哪些经验可以沉淀为后续规则。

## 目标

生成一个可复用的版本复盘工作流，并沉淀为全局能力文件。
