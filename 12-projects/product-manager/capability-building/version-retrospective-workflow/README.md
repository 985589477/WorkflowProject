# 版本复盘工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-13

## 目标

建设产品经理能力体系中的版本复盘工作流。

本项目负责在一个版本完成、上线或阶段结束后，复盘目标达成、需求交付、变更影响、质量问题、协作问题、用户反馈和后续改进。

它解决的是“版本做完以后如何总结事实、分析原因、沉淀经验、指导下一轮产品决策”的问题，不替代版本规划、需求变更评估和项目管理总结。

## 项目职责

这个项目负责生成并验证产品经理版本复盘工作流。

它不直接评价个人表现，而是定义后续产品经理如何复盘版本结果和产品过程。

## 角色

- 产品经理能力体系架构师。
- 版本复盘工作流架构师。
- 输出质量评审专家。

## 输入材料

输入材料可以来自：

- 版本规划。
- 产品路线图。
- PRD。
- 验收标准。
- 需求变更评估。
- 上线结果。
- 用户反馈。
- 数据表现。
- 设计、开发、测试和运营反馈。
