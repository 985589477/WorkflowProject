# 用户故事生成工作流建设项目

状态: completed
角色: product-manager
项目类型: capability-building
创建日期: 2026-10-12

## 目标

建设产品经理能力体系中的用户故事生成工作流。

本项目负责把 PRD、用户场景、功能规划和功能说明转化为用户视角的故事表达，让设计、开发和测试理解“谁在什么场景下为什么需要这个功能”。

## 项目职责

这个项目负责生成并验证产品经理用户故事生成工作流。

它不直接长期维护某个具体产品的用户故事，而是定义后续产品经理如何从需求、PRD 和功能规划生成用户故事。

## 何时使用

当你要建设、优化或评审用户故事生成能力时，使用这个项目。

当你要执行一次具体用户故事输出任务时，使用本项目沉淀出的全局工作流：

```text
04-workflows/product-manager/user-story-workflow.md
```
