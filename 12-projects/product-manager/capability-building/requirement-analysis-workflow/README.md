## 目标

建设产品经理能力体系中的第一个细分能力：需求分析工作流。

该项目负责把“需求分析能力”从能力地图落地为可复用 workflow。

## 项目职责

这个项目负责生成并验证产品经理需求分析工作流。

它承担的职责不是生成某个具体需求分析结果，而是定义后续产品经理如何把想法、需求草稿、会议纪要、用户反馈等输入整理成结构化需求分析。

## 何时使用

当你要建设或优化产品经理的需求分析能力时，使用这个项目。

当你要执行一次具体需求分析任务时，使用本项目沉淀出的全局工作流：

```text
04-workflows/product-manager/requirement-analysis-workflow.md
```
