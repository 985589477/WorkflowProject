# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```

## 决策：优先建设需求分析工作流

### 背景

产品经理能力体系项目推荐优先建设需求分析能力。

### 决策

创建并完成：

```text
12-projects/product-manager/capability-building/requirement-analysis-workflow/
```

并将输出沉淀到：

```text
04-workflows/product-manager/requirement-analysis-workflow.md
```

### 原因

需求分析是 PRD、功能规划和验收标准的上游能力。先稳定需求分析，后续产品经理能力建设会更稳。

### 影响

后续 PRD 工作流应以需求分析输出为上游输入。

### 日期

2026-10-12

## 决策：暂不生成需求分析模板和评分表

### 背景

能力体系中提到需求分析后续需要 template 和 evaluation。

### 决策

本项目只沉淀 workflow，暂不沉淀模板和评分表。

### 原因

模板和评分表需要真实需求分析项目验证后再设计，否则容易空泛。

### 影响

下一步应创建真实需求分析项目，验证 workflow 后再沉淀模板和评分表。

### 日期

2026-10-12
