# 信息架构

## 目的

本文件用于补齐 PRD 评审中指出的页面级信息架构缺口，帮助后续 UI 设计和开发拆解承接。

## 页面结构

```text
资产导航首页
├── 顶部概览
├── 筛选区
├── 资产列表
├── 项目列表
└── 推荐下一步

资产详情页
├── 基础信息
├── 适用场景
├── 输入要求
├── 输出结果
├── 使用示例
├── 关联案例
└── 优化记录

项目详情页
├── 项目基础信息
├── 当前状态
├── 推荐下一步
├── 关键产物
├── 使用资产
└── 沉淀记录
```

## 首页字段

| 字段 | 说明 | 来源 |
| --- | --- | --- |
| 角色 | 项目或资产所属角色 | 目录路径、README |
| 项目类型 | capability-building、real-cases、experiments | 目录路径、README |
| 项目名称 | 项目标题 | README 一级标题 |
| 状态 | draft、completed 等 | README 状态字段 |
| 项目职责 | 项目负责什么 | README 项目职责 |
| 何时使用 | 使用场景 | README 何时使用 |
| 推荐下一步 | 下一步建议 | 00-progress/next-actions.md |

## 资产详情字段

| 字段 | 说明 | 来源 |
| --- | --- | --- |
| 资产名称 | workflow、template、scorecard 等名称 | 文件名或标题 |
| 资产类型 | workflow、template、scorecard、example、knowledge | 所在目录 |
| 资产职责 | 解决什么问题 | 文件目的或 README |
| 输入要求 | 使用前需要什么材料 | 文件输入要求 |
| 输出结果 | 使用后会得到什么 | 文件产出说明 |
| 使用示例 | 可复制话术或命令 | 项目索引或模板 |
| 关联案例 | 哪些项目用过它 | 项目 README、lessons |
| 优化记录 | 后续如何改进 | 06-lessons |

## 项目详情字段

| 字段 | 说明 | 来源 |
| --- | --- | --- |
| 项目目标 | 项目要解决什么 | README 目标 |
| 当前状态 | 项目进展 | README 当前状态 |
| 推荐下一步 | 继续项目时该做什么 | 00-progress/next-actions.md |
| 关键产物 | 项目输出文件 | README 关键产物 |
| 输入材料 | 项目输入来源 | README 输入材料 |
| 使用工作流 | 本项目使用哪些 workflow | README 使用的工作流 |
| 使用模板 | 本项目使用哪些 template | README 使用的模板 |
| 沉淀记录 | 是否提升到全局资产 | 06-lessons |

## 空状态

### 没有筛选结果

显示：

```text
没有找到匹配的项目或资产，请调整筛选条件。
```

### 项目缺少 README

显示：

```text
该项目缺少 README，暂时无法展示完整信息。
```

### 项目缺少下一步

显示：

```text
该项目还没有填写推荐下一步。
```

## 第一版交互要求

- 筛选项变化后，列表应立即更新。
- 项目卡片应优先展示职责、状态和下一步。
- 资产详情应优先展示适用场景和使用示例。
- 所有路径都应可复制或容易识别。
- 不在第一版实现在线编辑。

## 给 UI 设计的输入建议

UI 设计阶段应重点设计：

- 首页信息密度。
- 筛选区布局。
- 项目卡片结构。
- 资产详情页结构。
- 项目详情页结构。
- 空状态。
- 长文本截断和展开方式。
