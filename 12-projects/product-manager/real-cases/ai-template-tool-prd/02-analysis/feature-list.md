# 功能清单

## 核心功能

| 模块 | 功能 | 来源 |
| --- | --- | --- |
| 资产导航首页 | 展示角色、项目类型、资产类型和资产列表 | 用户需要知道当前有什么、能用什么 |
| 筛选能力 | 按角色、项目类型、资产类型筛选 | 用户需要快速找到适合当前任务的资产 |
| 资产详情 | 展示资产职责、适用场景、输入要求、输出结果、使用示例 | 用户需要判断资产是否适合当前任务 |
| 项目详情 | 展示项目目标、当前状态、推荐下一步、关键产物 | 用户需要继续已有项目 |
| 使用示例 | 展示可复制的启动话术 | 用户需要低成本启动项目 |
| 关联案例 | 展示资产被哪些真实项目验证过 | 用户需要判断资产可靠性 |
| 优化记录 | 展示反馈、问题和后续优化方向 | 用户需要持续改进资产 |
| 刷新说明 | 告诉用户如何刷新索引和 dashboard | 用户需要知道新增或修改后如何同步 |

## 辅助功能

- 状态标签：draft、completed、validated、deprecated。
- 推荐下一步摘要。
- 关键产物路径展示。
- 全局资产与真实案例之间的关联展示。

## 第一版排除功能

- 在线编辑文档。
- 自动调用 AI 生成结果。
- 多账号权限。
- 模板市场。
- 复杂图表统计。
