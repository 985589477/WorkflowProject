# 用户角色和场景

## 用户角色

### 当前维护者

需要经常维护 WorkflowProject，知道当前有哪些能力、项目和模板。

### AI 协作使用者

需要使用已有 workflow、template、scorecard 或 example 完成具体项目。

### 能力建设者

需要继续建设产品、设计、开发、测试等角色能力体系。

## 核心场景

### 场景 A：我有一个模糊想法

用户希望知道应该使用哪个工作流，以及如何把想法变成标准输入、需求分析或 PRD。

### 场景 B：我想继续一个项目

用户几天后回来，忘记某个项目是干什么的，需要快速查看项目职责、当前状态和推荐下一步。

### 场景 C：我想优化一个能力

用户希望查看某个能力已有的 workflow、template、真实案例和评分表，然后决定下一步优化什么。

### 场景 D：我想沉淀经验

用户完成真实项目后，希望判断是否应该沉淀为 example、template、scorecard 或 knowledge。

## 主路径

1. 用户打开资产导航首页。
2. 用户选择角色。
3. 用户选择项目类型或资产类型。
4. 用户查看推荐资产。
5. 用户进入资产详情或项目详情。
6. 用户复制启动话术或查看下一步。
7. 用户执行项目。
8. 用户记录反馈和沉淀建议。
