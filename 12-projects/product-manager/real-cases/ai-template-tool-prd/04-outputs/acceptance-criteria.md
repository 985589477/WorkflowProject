# 验收标准

## 资产导航首页

- 用户可以看到按角色分组的项目和资产。
- 用户可以看到项目类型分组。
- 用户可以看到每个项目的状态、职责、关键产物和推荐下一步。
- 新增项目后，运行 `python3 tools/refresh_maps.py` 可以同步到总览数据。

## 筛选能力

- 用户可以按角色筛选。
- 用户可以按项目类型筛选。
- 用户可以按资产类型筛选。
- 筛选后列表内容应与选择条件一致。

## 资产详情

- 用户可以看到资产职责。
- 用户可以看到何时使用。
- 用户可以看到输入要求和输出结果。
- 用户可以看到至少一个使用示例。
- 如果存在关联案例，应展示案例路径。

## 项目详情

- 用户可以看到项目目标。
- 用户可以看到当前状态。
- 用户可以看到推荐下一步。
- 用户可以看到关键产物。
- 用户可以复制或识别启动方式。

## 使用示例

- 能根据能力建设项目生成继续建设话术。
- 能根据真实使用项目生成真实任务启动话术。
- 话术中必须包含项目路径。
- 话术中必须说明用户需要填写的内容。

## 关联案例

- 能展示某个 workflow 或 template 已被哪些真实项目使用。
- 能展示验证结论。
- 能展示后续优化建议。

## 优化记录

- 项目结束后能记录是否需要沉淀。
- 能记录应沉淀到 example、template、scorecard 或 knowledge。
- 能记录不沉淀的原因。

## 不做范围验收

- 第一版不出现账号登录设计。
- 第一版不出现权限管理设计。
- 第一版不出现模板市场设计。
- 第一版不要求自动执行 AI 全流程。
- 第一版不把在线编辑器作为必要功能。
