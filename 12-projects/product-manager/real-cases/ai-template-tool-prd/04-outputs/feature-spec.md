# 功能说明

## 1. 资产导航首页

### 目标

让用户快速看到当前 WorkflowProject 中可用的角色、项目类型、资产类型和核心资产。

### 用户操作

- 打开 dashboard 或项目总览。
- 查看不同角色下的能力建设项目、真实使用项目和实验项目。
- 查看 workflow、template、scorecard、example 等资产入口。

### 系统行为

- 展示项目和资产的分组。
- 展示每个项目的状态、职责、何时使用、关键产物和推荐下一步。
- 展示刷新时间或数据来源。

## 2. 筛选能力

### 目标

帮助用户按当前任务快速定位资产。

### 筛选维度

- 角色：product-manager、developer、ui-designer、mixed 等。
- 项目类型：capability-building、real-cases、experiments。
- 资产类型：workflow、template、scorecard、example、knowledge。
- 状态：draft、completed、validated、deprecated。

## 3. 资产详情

### 目标

让用户判断某个资产是否适合当前任务。

### 展示内容

- 资产名称。
- 资产职责。
- 何时使用。
- 输入要求。
- 输出结果。
- 使用示例。
- 关联案例。
- 后续优化建议。

## 4. 项目详情

### 目标

让用户快速恢复上下文并继续项目。

### 展示内容

- 项目目标。
- 项目职责。
- 当前状态。
- 推荐下一步。
- 关键产物。
- 启动方式。
- 使用过的 workflow、template 和 scorecard。

## 5. 使用示例

### 目标

降低用户启动项目的表达成本。

### 系统行为

- 根据项目类型展示不同启动话术。
- 能复制项目路径。
- 能说明输入要写在哪里、输出会保存在哪里。

## 6. 关联案例

### 目标

让用户知道某个资产是否被真实项目验证过。

### 展示内容

- 关联项目路径。
- 验证结论。
- 产物链接。
- 发现的问题。
- 后续优化建议。

## 7. 优化记录

### 目标

支持从真实项目反向优化全局资产。

### 展示内容

- 使用反馈。
- 卡点。
- 评审扣分点。
- 是否需要提升到全局模板、评分表或知识库。

## 8. 刷新说明

### 目标

让用户知道新增或修改项目后如何同步总览。

### 展示内容

```bash
python3 tools/refresh_maps.py
```

说明该命令会刷新：

- 项目索引。
- dashboard 数据。
- XMind 文件。
