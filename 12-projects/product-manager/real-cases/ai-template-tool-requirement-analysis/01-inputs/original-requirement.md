# 原始需求

## 用户原始想法

我想做一个管理 AI 提示词模板的工具，可以保存、分类、复用和优化提示词。

## 背景材料

当前 WorkflowProject 已经开始沉淀不同角色、不同流程、不同模板和不同案例。

随着项目数量增加，用户会遇到以下问题：

- 不容易快速知道当前有哪些模板。
- 不容易判断某个模板适合什么场景。
- 不容易复用历史上验证过的提示词结构。
- 不容易记录某个模板使用后的效果。
- 不容易把一次项目中的好经验沉淀回全局模板。

## 已有事实

- 项目中已经存在全局模板目录。
- 项目中已经存在项目索引和可视化面板。
- 用户希望降低后续使用成本。
- 用户不喜欢只靠目录记忆项目和能力。

## 约束条件

- 先面向个人使用。
- 优先服务 WorkflowProject 当前项目。
- 初期不追求复杂权限、团队协作和商业化功能。
- 输出需要能进入后续 PRD 或功能规划。

## 期望后续输出

先输出需求分析，再决定是否进入 PRD。

## 待确认信息

- 这个工具只管理提示词模板，还是也管理 workflow、案例和评分表。
- 是否需要做成 React 可视化界面。
- 是否需要自动读取当前项目文件并生成索引。
- 是否需要记录每次模板使用后的评分和复盘。
