# 评审扣分点解决方案

## 目的

本文件用于解决 `05-review/output-review.md` 中指出的扣分点，让需求分析结果更适合进入 PRD。

## 扣分点 1：产品边界还不够稳定

### 问题说明

当前需求中同时出现了：

- 提示词模板管理。
- workflow 管理。
- 案例管理。
- 评分表管理。
- 项目使用记录。

如果不先定义边界，后续 PRD 很容易膨胀成“AI 协作资产管理平台”，导致第一版过大。

### 推荐解决方案

第一版产品定位为：

```text
AI 协作资产索引与使用入口
```

第一版不只管理提示词模板，但也不做复杂平台。

纳入第一版的资产类型：

- workflow：告诉用户当前任务应该怎么跑。
- template：告诉用户具体提示词或输出格式怎么写。
- scorecard：告诉用户如何评审输出质量。
- example：告诉用户参考过去怎么做。

暂不纳入第一版的能力：

- 多人协作。
- 权限管理。
- 商业模板市场。
- 自动调度 AI 完成全流程。
- 复杂统计报表。

### 边界决策

第一版不是“提示词收藏夹”，而是 WorkflowProject 的资产导航层。

它的核心职责是：

```text
帮用户找到当前任务该用什么资产，并知道如何启动。
```

## 扣分点 2：缺少真实用户使用路径

### 问题说明

原需求分析只列出了场景，但没有描述用户从进入工具到完成任务的连续动作。

### 推荐用户路径

#### 路径 A：我有一个模糊想法

1. 用户进入资产导航界面。
2. 用户选择角色，例如产品经理。
3. 用户选择任务类型，例如需求分析。
4. 系统推荐可用 workflow、template、scorecard 和参考案例。
5. 用户复制启动话术，或创建一个真实使用项目。
6. 用户把想法交给 AI。
7. AI 生成标准输入和需求分析。
8. 用户根据评分表评审结果。
9. 项目结束后记录使用反馈。

#### 路径 B：我想优化一个能力

1. 用户进入资产导航界面。
2. 用户选择能力建设项目。
3. 用户查看该能力当前已有资产。
4. 用户查看真实案例验证结果。
5. 用户决定优化 workflow、template 或 scorecard。
6. 用户完成修改后刷新项目索引和可视化视图。

#### 路径 C：我忘了某个项目是干什么的

1. 用户打开项目索引或 dashboard。
2. 用户按角色和项目类型筛选。
3. 用户查看项目职责、何时使用、关键产物和推荐下一步。
4. 用户复制启动方式继续项目。

## 扣分点 3：成功标准还可以更量化

### 问题说明

原需求分析中有成功标准，但还不够便于验收。

### 推荐成功标准

第一版成功标准：

| 指标 | 合格标准 |
| --- | --- |
| 找到资产 | 用户能在 1 分钟内找到某个任务可用的 workflow 或 template。 |
| 理解用途 | 用户看完资产说明后，能判断这个资产是否适合当前任务。 |
| 启动项目 | 用户能复制启动话术，并明确输出目录。 |
| 追踪结果 | 每个真实使用项目都能记录使用的 workflow、template 和 scorecard。 |
| 反向沉淀 | 每个完成项目都能判断是否需要沉淀为 example、template 或 knowledge。 |
| 可视化同步 | 新增或修改项目后，运行 `python3 tools/refresh_maps.py` 能更新索引和 dashboard 数据。 |

## 扣分点 4：下游可用性仍有提升空间

### 问题说明

当前需求分析可以进入 PRD，但 PRD 还需要更明确的信息架构。

### 推荐第一版信息架构

```text
资产导航首页
├── 角色筛选
├── 项目类型筛选
├── 资产类型筛选
├── 资产列表
└── 推荐启动方式

资产详情
├── 资产职责
├── 何时使用
├── 输入要求
├── 输出结果
├── 使用示例
├── 关联案例
└── 优化记录

项目详情
├── 项目目标
├── 当前状态
├── 推荐下一步
├── 使用资产
├── 关键产物
└── 复盘沉淀
```

## 建议进入 PRD 的版本范围

### PRD 第一版要写

- 资产导航首页。
- 资产详情。
- 项目详情。
- 使用示例。
- 关联案例。
- 优化记录。
- 刷新机制说明。

### PRD 第一版不写

- 用户登录。
- 权限管理。
- 在线编辑器。
- 自动执行 AI 全流程。
- 模板市场。
- 商业化。

## 更新后的结论

如果按本文件补齐边界、用户路径和成功标准，当前需求分析可以从 `26/30` 提升到接近 `29/30`。

它已经足够进入 PRD 初稿。
