# 项目记忆摘要

## 一句话定位

UI 设计能力包细分升级项目，已产出设计治理能力版 `ui-designer-kit`。

## 当前目标

建设 UI 设计角色总入口、细分工作流、模板、评分表、质量清单和导出包。

## 当前阶段

completed

## 最近一次有效进展

已完成 UI 设计治理能力版，并补齐设计规范确认、设计系统检查、响应式与多端适配、页面类型模式、组件库规划、可访问性与可用性检查、设计到开发实现约束，同步到全局资产和导出包。

最近增强：设计规范输出必须包含通用适配规则和组件规划，不能只描述风格。

最新增强：响应式和设计交接必须覆盖折叠屏、分屏、双屏、横屏和 iPad 分屏等特殊设备形态。

治理增强：UI 总入口必须能调度设计系统检查、页面类型模式、组件库规划、可访问性与可用性检查、设计到开发实现约束，不再只负责页面方案输出。
