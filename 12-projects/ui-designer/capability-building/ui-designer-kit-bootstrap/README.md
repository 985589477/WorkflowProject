## 目标

建设并细化 UI 设计角色能力包。

## 项目职责

这个项目负责启动并细化 UI 设计能力体系，沉淀总入口、细分工作流、模板、评分表和导出包。

## 何时使用

当你要继续完善 UI 设计角色、拆分页面评审、组件设计、设计系统检查等细分能力时，使用这个项目。

当你要执行一次具体 UI 设计任务时，优先使用：

```text
14-exports/ui-designer-kit/START-HERE.md
```
