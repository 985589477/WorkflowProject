# 输入分析

## 任务类型

这是框架刷新项目，不是从 0 到 1 的框架搭建项目。

## 当前框架变化

相较早期 bootstrap，当前项目已经增加了以下关键能力：

| 变化 | 说明 |
| --- | --- |
| 可视化导图 | `13-visual-maps/` 统一管理 XMind 和大纲 |
| 能力导出层 | `14-exports/` 存放可独立使用的能力包 |
| 可视化控制台 | `15-dashboard/` 提供 React dashboard |
| 项目索引 | `12-projects/project-index.md` 支持按项目查看职责和启动方式 |
| 执行 skill | `workflowproject-executor` 规范项目执行方式 |
| 产品经理能力体系 | 产品经理主链路已从想法到复盘闭环 |

## 旧 bootstrap 的定位变化

旧项目：

```text
12-projects/mixed/capability-building/workflowproject-framework-bootstrap/
```

应从当前框架项目降级为历史档案。

推荐归档到：

```text
99-archive/projects/workflowproject-framework-bootstrap/
```

## 当前框架职责

当前 WorkflowProject 分为：

- 系统规则层：`00-system/`
- 治理层：`01-governance/`
- 角色层：`02-roles/`
- 输入层：`03-inputs/`
- 工作流层：`04-workflows/`
- 标准层：`05-standards/`
- 模板层：`06-templates/`
- 提示词层：`07-prompts/`
- 输出层：`08-outputs/`
- 案例层：`09-examples/`
- 知识层：`10-knowledge-base/`
- 评估层：`11-evaluations/`
- 项目执行层：`12-projects/`
- 可视化导图层：`13-visual-maps/`
- 能力导出层：`14-exports/`
- 可视化控制台层：`15-dashboard/`
- 归档层：`99-archive/`

## 结论

需要保留 bootstrap 的历史价值，但不应让它继续混在当前项目索引中承担“最新框架”的角色。
