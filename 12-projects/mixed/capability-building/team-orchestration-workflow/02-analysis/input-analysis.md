# 输入分析

## 需求判断

这是一个 mixed 角色能力建设项目，不是具体业务任务。

它要解决的问题是：当前产品经理、UI、开发、测试角色都已经具备单角色能力，但缺少一个团队级总调度，让它们可以在完整项目链路中协作。

## 关键能力拆分

1. 角色接管判断：判断用户输入应该由哪个角色先接管，哪些角色后续参与。
2. 阶段优先级：默认产品 -> UI -> 开发 -> 测试，但 bug、代码、设计、上线类任务可以改变优先级。
3. 交接检查：下游角色必须检查上游产物是否看得懂。
4. 互相验收：开发交付后需要产品、UI、测试分别验收。
5. 阻塞反馈：沟通不畅时停止推进，明确阻塞点和补充问题。
6. badcase 回流：把反复出现的问题回到对应角色能力建设项目优化。

## 需要提升到全局的资产

- mixed 团队总调度工作流。
- mixed 团队总调度模板。
- mixed 团队总调度评分表。

## 不做的事情

- 不替代产品、UI、开发、测试各自的细分工作流。
- 不直接实现代码。
- 不直接输出完整业务交付物，而是负责组织协作链路。
