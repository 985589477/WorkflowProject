# 原始需求

用户希望在 `mixed` 里添加一个项目，用来总调度产品经理、UI 设计师、开发工程师、测试工程师。

核心要求：

- 当用户提出相关需求时，各个角色需要检查是否需要自己接管部分任务内容。
- 总调度需要按照优先级依次引导用户往下进行。
- 需要有跨角色反馈，例如：
  - 产品输出的东西，开发、UI、测试是否能看得懂。
  - UI 输出的东西，开发和测试是否能看得懂。
  - 开发交付的东西，是否能通过产品、UI、测试验收。
- 这些角色应该像一个完整 team，互相合作且各司其职。
- 若出现沟通不畅，需要反馈给用户。
- 用户可以拿着 badcase 回到对应 project 里进行细分优化。
