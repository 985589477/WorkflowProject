# 决策记录

## 使用说明

这里记录项目执行过程中重要决策的原因。

进度记录回答“做到了哪一步”，决策记录回答“为什么这么做”。

## 记录模板

```md
## 决策：{决策标题}

### 背景

为什么出现这个问题？

### 决策

最终决定做什么？

### 原因

为什么这样做？

### 影响

这个决策会影响哪些文件、流程或后续方向？

### 日期

YYYY-MM-DD
```

## 决策：新增 14-exports 作为能力导出层

### 背景

WorkflowProject 已经可以生产、评审和沉淀能力，但当用户需要把某个角色能力拆分出去给产品、开发或 UI 单独使用时，现有目录没有专门承载外部能力包的位置。

### 决策

新增：

```text
14-exports/
```

作为可脱离 WorkflowProject 独立使用的能力包导出区。

### 原因

`12-projects/` 是项目执行记录，`04-workflows/` 和 `06-templates/` 是内部复用资产，`09-examples/` 是案例沉淀。它们都不适合作为“外部交付包”的最终位置。

### 影响

后续可以将产品经理、开发、UI 等角色能力导出为：

```text
14-exports/product-manager-kit/
14-exports/developer-kit/
14-exports/ui-designer-kit/
```

### 日期

2026-10-13
