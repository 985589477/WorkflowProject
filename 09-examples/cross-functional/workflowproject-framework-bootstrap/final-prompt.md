# 正式提示词

来源项目：

```text
12-projects/mixed/capability-building/workflowproject-framework-bootstrap/03-prompts/final-prompt.md
```

## 提示词正文

你是一名精通 AI 开发协作、提示词工程、文档工程和项目治理的架构师。

请基于以下目标，为当前项目设计并搭建一个长期可扩展的 AI 工作流文档工程框架。

## 背景

用户希望把当前文件夹建设为一个工作流文档项目。该项目用于将原始资料、工作需求、文档内容和经验，转化为可提供给 AI 使用的标准化提示词文档。

## 任务目标

请完成以下工作：

1. 设计完整目录结构。
2. 区分全局可复用资产与具体项目现场。
3. 建立项目治理规范。
4. 建立输入、模板、提示词、输出、案例、评审等标准。
5. 建立 meta templates，让 AI 可以辅助生成模板、提示词、评审和案例。
6. 建立项目模板。
7. 生成用于理解框架和操作流程的 XMind 导图。
8. 将当前 WorkflowProject 框架本身作为第一个真实项目进行沉淀。

## 输出要求

输出应包括：

- Markdown 文档框架。
- 可复用目录结构。
- 治理文档。
- 标准文档。
- meta templates。
- 通用工作流。
- 第一个项目样板。
- XMind 文件和 Markdown 大纲。

## 质量标准

- 全局目录和项目目录职责清晰。
- 不混淆 template、prompt、output、example。
- 每个目录有明确用途。
- 项目可支持后续产品、开发、UI 设计等角色扩展。
- 当前框架能被后续真实任务复用。
- 重要结构调整应可通过 governance 和 decision records 管控。
