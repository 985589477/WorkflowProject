## 输出摘要

本项目最终搭建出一个可实际使用的 AI 工作流文档工程框架。

## 核心成果

- 建立 `00-system/`：系统规则、架构、术语、命名、语言、生命周期、操作指南、快速开始、进度汇报规则。
- 建立 `01-governance/`：贡献规则、变更管理、版本规则、评审流程、质量门禁、架构决策记录。
- 建立 `02-roles/`：通用、产品经理、开发工程师、UI 设计师、研究员、市场营销等角色定义。
- 建立 `04-workflows/`：输入分析、模板生成、正式提示词生成、输出评审、案例提取、模板迭代、资产提升、项目执行总控。
- 建立 `05-standards/`：输入、角色、工作流、模板、正式提示词、输出、案例、项目、评审标准和质量检查清单。
- 建立 `06-templates/`：meta 模板和通用任务模板。
- 建立 `10-knowledge-base/`：知识库写作说明。
- 建立 `11-evaluations/`：通用输出评分规则和项目完成检查表。
- 建立 `12-projects/`：项目模板和第一个样板项目。
- 建立 `13-visual-maps/`：XMind 导图与 Markdown 大纲统一管理。
- 建立 `tools/`：项目创建脚本和导图生成脚本。

## 已验证能力

- 可通过 `tools/create_project.py` 创建标准项目。
- 新项目会自动生成 `00-progress/progress-log.md`。
- 文件职责图可自动扫描当前目录生成。
- 文档正文遵循中文优先原则。
- 执行项目时可记录当前进度、调度角色、使用工作流、使用模板和下一步。
