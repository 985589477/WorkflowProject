# WorkflowProject 框架启动案例

状态: accepted
类型: cross-functional
来源项目: `12-projects/mixed/capability-building/workflowproject-framework-bootstrap/`

## 案例说明

这是 WorkflowProject 的第一个正式优秀案例。

它记录了一次从模糊需求出发，逐步搭建 AI 工作流文档工程框架的完整过程。

## 案例价值

这个案例可用于：

- 参考如何从原始想法搭建文档工程框架。
- 参考如何区分全局资产和项目现场。
- 参考如何建立系统规则、治理规则、工作流、标准、模板和评估体系。
- 参考如何降低项目使用成本。
- 参考如何记录项目执行进度和调度角色。

## 文件结构

```text
input.md         原始需求
workflow.md      使用的工作流和执行路径
template.md      使用的模板和模板能力
final-prompt.md  本次正式提示词
output.md        最终框架输出
review.md        输出评审
lessons.md       复盘经验
progress.md      执行进度和调度记录
```

## 使用方式

后续遇到类似“从零搭建 AI 文档工作流项目”的任务时，可以把本案例作为参考材料提供给 AI。

推荐提示：

```text
请参考 09-examples/cross-functional/workflowproject-framework-bootstrap/ 这个案例，
帮我规划一个新的 AI 工作流文档项目。
请沿用其中的项目分层、治理方式、执行流程、进度记录和沉淀方式。
```
