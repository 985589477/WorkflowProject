# 使用的工作流

## 总控流程

本项目使用的总控流程：

```text
04-workflows/common/project-execution-workflow.md
```

执行路径：

```text
创建项目
-> 放入原始材料
-> 输入分析
-> 设计框架
-> 建立系统规则
-> 建立治理规则
-> 建立工作流
-> 建立标准
-> 建立模板
-> 建立可视化导图
-> 降低使用成本
-> 输出评审
-> 复盘
-> 资产提升
```

- 从模糊需求生成项目架构。
- 从项目过程生成可复用规则。
- 从项目现场沉淀正式案例。
- 通过 `00-progress/progress-log.md` 记录执行进度和调度角色。
