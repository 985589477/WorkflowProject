# 项目完成检查表

## 用途

用于判断 `12-projects/` 下的一个项目是否已经完成。

## 检查项

| 检查项 | 是否完成 | 说明 |
| --- | --- | --- |
| 已创建项目 README |  | 说明目标、角色、输入、工作流、模板、状态 |
| 已记录进度 |  | `00-progress/progress-log.md` |
| 已放入原始材料 |  | `01-inputs/` |
| 已完成输入分析 |  | `02-analysis/` |
| 已生成正式提示词 |  | `03-prompts/` |
| 已保存 AI 输出 |  | `04-outputs/` |
| 已完成输出评审 |  | `05-review/` |
| 已完成复盘 |  | `06-lessons/` |
| 已判断是否沉淀 |  | 是否进入模板、案例、知识库或评估体系 |
| 已记录调度角色 |  | 每个关键阶段调度了谁 |

## 评分建议

- 0-5 项完成：项目未完成。
- 6-8 项完成：项目基本完成，但不建议沉淀。
- 9-10 项完成：项目完成，可以判断是否沉淀为案例或知识。

## 结论模板

```text
项目状态：
完成项：
缺失项：
是否建议沉淀：
下一步：
```
