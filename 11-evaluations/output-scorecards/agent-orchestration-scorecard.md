# Agent 调度验收表

## 评分规则

| 项目 | 分值 | 检查结果 |
| --- | ---: | --- |
| 是否正确区分简单任务和组合任务 | 20 |  |
| 简单任务是否只调用 Skill 且没有创建子 Agent | 15 |  |
| 组合任务是否由父 Agent 建立任务树并创建真实子 Agent | 20 |  |
| 子 Agent 是否拥有清晰的范围、输入和验收标准 | 15 |  |
| 子 Agent 是否返回结构化结果和验证证据 | 10 |  |
| 是否处理文件冲突、依赖和交接 | 10 |  |
| 运行环境不支持子 Agent 时是否诚实降级并请求确认 | 10 |  |
| **总分** | **100** |  |

## 通过标准

- 90-100：可以作为父子 Agent 调度流程使用。
- 75-89：可以试运行，但需要补充边界或验证。
- 低于 75：不得宣称已经完成真实子 Agent 协作。
