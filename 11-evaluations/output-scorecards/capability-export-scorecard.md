# 能力导出评分表

## 适用对象

用于评估从 WorkflowProject 导出的角色能力包或专项能力包是否完整、清晰、可独立使用、可维护。

## 评分维度

| 维度 | 分值 | 评估标准 |
| --- | --- | --- |
| 导出边界清晰度 | 5 | 是否明确导出对象、使用对象和适用场景 |
| 资产完整性 | 5 | 是否包含必要 workflow、template、scorecard、knowledge 或 example |
| 独立可用性 | 5 | 是否离开 WorkflowProject 也能理解和使用 |
| 入口清晰度 | 5 | README 是否说明怎么启动、怎么选择能力、会输出什么 |
| 来源可追溯性 | 5 | 是否有 `manifest.md` 记录来源文件和导出时间 |
| 统一入口完整度 | 5 | `START-HERE.md` 是否使用统一格式，包含手动启动、自动读取配置、执行顺序和输出确认格式 |
| 精简程度 | 5 | 是否剔除了无关内部过程材料 |
| 维护性 | 5 | 是否说明后续如何更新、同步和验证 |

总分：40 分。

## 结果判断

| 分数 | 判断 |
| --- | --- |
| 36-40 | 可以作为独立能力包使用 |
| 30-35 | 基本可用，但需要补充入口或来源说明 |
| 20-29 | 需要重新整理导出包 |
| 0-19 | 不建议交付或复用 |

## 扣分规则

- 没有 README：扣 5 分。
- 没有 `START-HERE.md`：扣 5 分。
- `START-HERE.md` 未使用统一格式：扣 3-5 分。
- 没有一句话启动入口：扣 3 分。
- 没有外部自动读取配置示例：扣 3 分。
- 没有执行前输出确认格式：扣 2 分。
- 没有 manifest：扣 5 分。
- 没有导出时间：扣 3 分。
- 缺少核心 workflow 或 template：扣 5 分。
- 包含大量无关项目过程材料：扣 3-5 分。
- 外部使用者无法知道如何启动：扣 5 分。
- 未说明维护方式：扣 3 分。

## 评审输出格式

```md
| 维度 | 分数 | 说明 |
| --- | --- | --- |

```
