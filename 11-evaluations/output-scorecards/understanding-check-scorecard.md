# 理解检查表

## 用途

用于检查用户是否真正理解 AI 刚刚做了什么，以及是否能判断下一步方向。

## 检查项

| 检查项 | 是否清楚 | 说明 |
| --- | --- | --- |
| 我知道 AI 刚刚完成了什么 |  |  |
| 我知道为什么要这样做 |  |  |
| 我知道新增了哪些文件 |  |  |
| 我知道修改了哪些文件 |  |  |
| 我知道这些变化有什么用 |  |  |
| 我知道应该先看哪个文件 |  |  |
| 我知道下一步有哪些选择 |  |  |
| 我知道 AI 调度了哪个角色 |  |  |
| 我知道使用了哪个工作流或模板 |  |  |
| 我能决定继续、暂停、改方向或沉淀 |  |  |

## 判断规则

- 8-10 项清楚：可以继续推进。
- 5-7 项清楚：可以推进，但需要补一段结果解释。
- 0-4 项清楚：不建议继续推进，应先让 AI 解释当前状态。

## 结果模板

```text
理解状态：
不清楚的点：
需要 AI 补充解释：
建议下一步：
```
