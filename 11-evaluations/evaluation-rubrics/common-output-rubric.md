# Common Output Rubric

## Score Scale

- 1：不可用，需要重做。
- 2：方向部分正确，但缺失严重。
- 3：基本可用，需要人工补充。
- 4：质量良好，可以进入后续工作。
- 5：高质量，可沉淀为案例。

## Dimensions

| Dimension | Question |
| --- | --- |
| Accuracy | 是否忠于输入资料 |
| Completeness | 是否覆盖任务要求 |
| Structure | 是否结构清晰 |
| Actionability | 是否可执行 |
| Traceability | 是否可追溯 |
| Reusability | 是否有复用价值 |
