# 评估体系

这里存放提示词和 AI 输出的测试、评分、对比和评估方法。

## 当前可用评估资产

### 通用评估

- `evaluation-rubrics/common-output-rubric.md`：通用输出评估规则。
- `output-scorecards/project-completion-scorecard.md`：项目完成度评分表。
- `output-scorecards/understanding-check-scorecard.md`：理解确认评分表。
- `output-scorecards/capability-export-scorecard.md`：能力导出评分表，用于判断角色能力包或专项能力包是否可以独立使用。

### 产品经理评估

- `output-scorecards/requirement-analysis-scorecard.md`：需求分析评分表，用于判断需求分析结果是否可以进入 PRD。
- `output-scorecards/prd-scorecard.md`：PRD 评分表，用于判断 PRD 是否可以进入 UI 设计、开发拆解或下一阶段。
- `output-scorecards/acceptance-criteria-scorecard.md`：验收标准评分表，用于判断验收标准是否可以进入测试用例、开发验收或上线验收。
- `output-scorecards/feature-planning-scorecard.md`：功能规划评分表，用于判断功能规划是否可以进入 UI 设计、开发拆解或版本规划。
- `output-scorecards/user-story-scorecard.md`：用户故事评分表，用于判断用户故事是否可以进入验收标准、UI 设计或开发拆解。
- `output-scorecards/user-feedback-scorecard.md`：用户反馈整理评分表，用于判断反馈整理结果是否可以进入需求分析、需求池或优先级判断。
- `output-scorecards/competitor-analysis-scorecard.md`：竞品分析评分表，用于判断竞品分析是否可以进入需求分析、产品策略或功能规划。
- `output-scorecards/priority-decision-scorecard.md`：优先级判断评分表，用于判断优先级结论是否可以进入版本规划、功能规划或开发排期。
- `output-scorecards/version-planning-scorecard.md`：版本规划评分表，用于判断版本规划是否可以进入路线图、开发排期或发布计划。
- `output-scorecards/product-strategy-scorecard.md`：产品策略判断评分表，用于判断产品方向、机会点或策略主题是否可以进入需求分析、优先级判断、版本规划或路线图。
- `output-scorecards/requirement-pool-scorecard.md`：需求池管理评分表，用于判断需求池是否可以支持需求分析、策略判断、优先级判断、PRD 或版本规划。
- `output-scorecards/product-roadmap-scorecard.md`：产品路线图评分表，用于判断路线图是否可以进入 PRD、版本规划、开发排期或团队沟通。
- `output-scorecards/requirement-change-evaluation-scorecard.md`：需求变更评估评分表，用于判断变更评估是否可以支持团队做变更决策。
- `output-scorecards/version-retrospective-scorecard.md`：版本复盘评分表，用于判断复盘结果是否可以支持下一轮需求池、路线图、版本规划或流程改进。

## 使用建议

如果是具体项目输出，优先查看项目内的 `05-review/`。

如果要评估某一类能力是否稳定，使用本目录下的全局评分表。
