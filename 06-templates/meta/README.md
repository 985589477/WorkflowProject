# Meta 模板

这里放用于生成、评审、优化其他提示词资产的模板。

常用顺序：

```text
idea-to-input-generator
-> template-generator
-> prompt-generator
-> output-reviewer
-> example-extractor
-> template-optimizer
```

## 当前模板

- `idea-to-input-generator.md`：把用户模糊想法整理成标准输入文档。
- `template-generator.md`：从原始资料生成可复用模板。
- `prompt-generator.md`：从模板和输入资料生成正式提示词。
- `project-runner.md`：按项目规则推进具体项目。
- `explainable-project-runner.md`：以可解释方式推进项目。
- `output-reviewer.md`：评审 AI 输出质量。
- `example-extractor.md`：把高质量任务整理成案例包。
- `template-optimizer.md`：根据案例和问题优化模板。
