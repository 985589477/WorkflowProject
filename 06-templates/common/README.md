# 通用模板

这里放跨角色可复用模板。

## 当前模板

- `project-governance-checklist-template.md`：检查真实项目治理基础、缺口、任务列表和文档同步情况。
- `framework-bootstrap-template.md`：项目框架搭建模板。
- `general-task-template.md`：通用任务模板。
- `capability-export-template.md`：能力导出模板，用于把角色能力或专项能力整理成独立能力包。
- `iteration-memory-summary-template.md`：项目记忆摘要模板，用于长期迭代记录压缩。
- `agent-task-brief-template.md`：父 Agent 分配子任务时使用的任务简报。
- `agent-result-report-template.md`：子 Agent 返回父 Agent 的结构化结果。
