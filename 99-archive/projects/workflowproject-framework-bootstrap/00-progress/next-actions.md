# 下一步判断

## 当前项目状态

```text
项目现场
-> 正式案例
-> 知识模式

```

## 可选方向

### 方向 A：开始真实业务项目

- 价值：验证框架是否能服务真实任务。
- 风险：会暴露角色模板不足。
- 建议：推荐。

### 方向 B：继续补框架基础设施

- 价值：短期看起来更完整。
- 风险：容易过度设计，增加使用成本。
- 建议：暂缓。

### 方向 C：补产品、开发、UI 角色模板

- 价值：为后续角色任务做准备。
- 风险：没有真实任务验证，模板可能空泛。
- 建议：等真实任务跑完后再补。

### 方向 D：优化可解释协作机制

- 价值：提升用户对 AI 执行过程的理解和把控。
- 风险：规则过多可能让流程变重。
- 建议：已完成第一版，后续通过真实项目验证。

## 推荐下一步

优先开始一个真实业务项目，使用：

```bash
python3 tools/create_project.py mixed your-real-task --type real-cases
```

如果任务明确属于开发、产品或 UI，再选择对应角色目录。
