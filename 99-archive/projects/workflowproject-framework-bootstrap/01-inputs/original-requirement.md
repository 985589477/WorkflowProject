# 原始需求

## 背景

用户希望在当前文件夹中开发一个类似工作流的文档项目。该项目的主要职责是帮助用户作为工作者，通过一个或多个文档，输出提供给 AI 使用的输入输出标准提示词文档。

## 逐步明确的需求

用户在讨论中逐步明确了以下需求：

- 项目需要支持从 input 到 example 的全过程。
- 项目中的多个步骤都需要 AI 协作生成。
- 项目需要是一个足够完善的大框架，而不是只为了前期省力。
- 项目不仅要搭建流程，还要管控当前项目自身的维护方式。
- 需要通过 XMind 思维导图查看项目结构和操作流程。
- 当前 WorkflowProject 框架本身应作为第一个真实项目来验证流程。

## 约束条件

- 项目以 Markdown 文档为主要载体。
- 全局目录负责长期复用资产。
- 具体任务应放在 `12-projects/` 下执行。
- 框架要支持后续扩展到产品经理、程序员、UI 设计师等多角色。

## 期望输出

产出一个可维护、可复用、可扩展的 AI 工作流文档工程框架，并形成第一个样板项目。
