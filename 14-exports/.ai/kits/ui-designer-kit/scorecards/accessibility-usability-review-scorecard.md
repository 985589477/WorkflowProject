# 可访问性与可用性检查评分表

适用对象：UI 可用性检查、无障碍检查、设计评审

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 任务可完成 | 20 | 用户是否能理解目标并完成核心任务 |
| 信息可理解 | 20 | 信息层级、文案、反馈和错误提示是否清楚 |
| 操作可用 | 20 | 点击区域、触控、键盘、焦点和恢复路径是否合理 |
| 视觉可读 | 20 | 颜色对比、字号、间距、状态区分是否可读 |
| 多端可用 | 20 | 移动端、平板、桌面、横屏和特殊设备是否可用 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可进入交付 |
| 75-89 | 可试用，需要补少量可用性问题 |
| 60-74 | 存在明显使用风险 |
| 0-59 | 不建议交付 |
