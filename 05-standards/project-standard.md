# Project Standard

## 项目目录必须包含

```text
project-name/
├── README.md
├── 01-inputs/
├── 02-analysis/
├── 03-prompts/
├── 04-outputs/
├── 05-review/
└── 06-lessons/
```

## README 必须说明

- 项目目标。
- 适用角色。
- 输入来源。
- 使用的工作流。
- 使用的模板。
- 当前状态。
- 是否有内容提升到全局资产。

## 项目结束时

需要判断：

- 是否产生可复用模板。
- 是否产生可沉淀案例。
- 是否产生知识库条目。
- 是否需要归档。
