# 语言使用规则

## 基本原则

项目文档默认使用中文。

只有在以下场景保留英文：

- 目录名、文件名、状态值等需要稳定引用的技术标识。
- prompt、template、workflow、input、output、review、example 等已成为项目核心术语的英文词。
- AI 工具、软件、协议或代码中的固定名称。
- 为了和文件路径、命令、脚本保持一致而必须使用的英文。

## 文档正文

文档标题、段落说明、操作步骤、评审结论、复盘内容优先使用中文。

不推荐在正文中使用不必要的英文标题，例如：

```text
Goal
Role
Inputs
Workflows
Templates
Status
Promotion
```

推荐改为：

```text
目标
角色
输入材料
使用的工作流
使用的模板
状态
沉淀与提升
```

## 文件路径

文件路径可以保留英文和数字，例如：

```text
12-projects/mixed/capability-building/workflowproject-framework-bootstrap/
06-templates/meta/template-generator.md
```

路径名优先追求稳定、短、可引用，不要求完全中文化。

## 模板字段

模板中面向人填写的字段优先使用中文。

可以保留英文占位符或术语，但必须在附近用中文解释。
