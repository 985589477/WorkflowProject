# 结果报告规则

## 目的

在 AI 完成任务后，让用户快速知道完成了什么、改了哪里、有什么用、下一步有哪些选择。

## 适用范围

适用于所有项目执行、文件修改、案例沉淀、知识提炼、模板新增和脚本更新。

## 执行后必须说明

每次完成关键操作后，AI 应输出：

```text
完成了什么：
新增了哪些文件：
修改了哪些文件：
这些变化有什么用：
你现在应该看哪里：
下一步建议：
风险或未完成：
```

## 使用要求

- 文件路径要明确。
- 不要只说“已完成”，要说明完成的意义。
- 如果有测试或验证，说明验证结果。
- 如果没有验证，明确说没有验证。
- 如果有多个下一步，按优先级列出。

## 示例

```text
完成了什么：已将 bootstrap 项目沉淀为正式案例。
新增了哪些文件：09-examples/cross-functional/workflowproject-framework-bootstrap/。
修改了哪些文件：promotion-notes.md、progress-log.md。
这些变化有什么用：后续类似框架搭建任务可以直接参考该案例。
你现在应该看哪里：案例 README。
下一步建议：从案例提炼知识模式。
风险或未完成：角色专属模板仍需真实项目验证。
```
